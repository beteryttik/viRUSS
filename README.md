# VIruss Client (Fabric 1.21.1)

Клиент с модульной системой (100+ модулей) и упором на FPS.

## Как собрать JAR
1. Залейте проект на GitHub (вся структура уже в этом ZIP).
2. GitHub Actions соберёт JAR автоматически: вкладка Actions -> последний запуск -> Artifacts -> viruss-client.
3. Положите `viruss-client-1.0.0.jar` в `.minecraft/mods` (нужны Fabric Loader 0.16.5+ и Fabric API).

## Управление
- Right Shift — меню модулей
- O — быстрый тоггл HUD
